웹앱의 데이터 사용

O-Ring Fit은 사용자가 입력한 치수와 조건을 브라우저 안에서 계산합니다. 입력한 설계값과 생성한 DXF는 운영자 서버로 전송하거나 저장하지 않습니다. DXF 다운로드는 사용자의 기기에서 직접 생성됩니다.

웹페이지의 광고

공개 GitHub Pages 버전에는 Google AdSense 하단 앵커 광고가 사용될 수 있습니다. 실제 광고는 Google의 사이트 승인과 광고 공급 상황에 따라 표시됩니다.

Google과 제3자 광고 제공업체는 쿠키, 웹 비콘, IP 주소 등의 정보를 사용해 광고를 제공하거나 측정할 수 있습니다. 광고 쿠키는 이 사이트 또는 다른 사이트의 이전 방문을 바탕으로 광고를 제공하는 데 사용될 수 있습니다.

Google의 파트너 사이트 데이터 사용 안내와 Google 개인정보처리방침에서 자세한 내용을 확인할 수 있습니다. 맞춤 광고 설정은 Google 내 광고 센터에서 관리할 수 있습니다.

호스팅과 문의

공개 웹사이트는 GitHub Pages에서 제공됩니다. 호스팅 서비스의 데이터 처리는 GitHub 개인정보처리방침을 참고하세요.

문의는 프로젝트 문의 페이지로 남길 수 있습니다. 공개 게시판이므로 개인정보는 작성하지 마세요.
