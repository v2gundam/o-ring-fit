# O-Ring Fit

허용 가능한 씰 공간에서 AS568 표준 오링 후보를 찾고, 정적 축방향 면 씰 글랜드 형상과 DXF를 만드는 브라우저 앱입니다.

## 현재 기능

- 원형 플랜지: 챔버 내경, 플랜지 외경, 내·외측 벽 여유 입력
- 둥근 사각형: 안쪽 금지 경계와 바깥쪽 허용 경계의 가로·세로·모서리 반경 입력
- AS568F 369개 치수 데이터에서 모든 적합 후보 검색
- 후보별 설치 신장/둘레 압축, 공차 최악조건, 글랜드 폭·깊이, 지지벽 계산
- 내부 가압, 내부 진공, 외부 가압과 액체·기체·진공 구분
- 선택한 후보에 따라 갱신되는 실치수 SVG 미리보기
- ASCII DXF R14, mm 단위 가공 도면 미리보기와 다운로드
- FKM(Viton™) 고정 재질과 미확정 경도·컴파운드 경고

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

`http://localhost:3000`을 브라우저에서 엽니다.

## 검증

```bash
npm test
```

이 명령은 배포 빌드와 함께 원형·둥근 사각형 공간 제약, 변형률 한계, 압력별 지지벽, 후보 없음 상태, DXF 단위와 폐곡선 형식을 시험합니다.
